# What I care about

I build agentic AI systems. I want to know about:

- New capabilities or architectural ideas for LLM agents: planning, memory, tool use,
  multi-agent coordination, long-horizon tasks, context engineering.
- Frameworks, libraries and services worth evaluating: LangGraph, OpenAI Agents SDK,
  Claude Code, DSPy, MCP, Arize Phoenix, and credible new entrants.
- Research with a genuine contribution, especially agent evaluation, reliability,
  reasoning, and security of agents.
- Production lessons: evals, observability, cost, latency, failure modes, security.

Lower priority: funding news, product marketing, model launches with no technical
detail, generic "AI will change everything" commentary, consumer chatbot features.
